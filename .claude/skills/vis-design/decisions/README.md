# Decision memory

`seed/` holds the generic declared solutions that ship with the skill (one or more per
problem archetype). A repository keeps its own records in `<repo>/.claude/vis-decisions/`
(created on first use), which take precedence over seeds with the same key.

- Key = (archetype, mode, reader profile, data-shape signature). See
  `references/decision-schema.md`.
- Seeds are never edited by the scripts. To override one for a project, accept the
  questionnaire with a different solution: a project record with the same key is written
  and shadows the seed. To hide a seed in a project, list its id under `disabled_seeds`
  in `project.yaml`.
- `index.json` is generated by `scripts/build_index.py`; do not edit it by hand.
- Hand-editing a record: keep the enumerated fields within `profiles/vocab.yaml`, then run
  `scripts/build_index.py --check` (seeds) or `scripts/record_decision.py --dry-run`
  (project records) to validate.
- Project `project.yaml`: `library`, `host`, `output_dir`, `disabled_seeds`, `updated`.
