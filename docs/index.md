# Santolina tutor

A math copilot that runs entirely on the Arduino UNO Q 4 GB, for the Qualcomm
challenge of Datathon FME 2026. It works with the
[M3Kang dataset](https://huggingface.co/datasets/qualcomm/M3Kang). The dataset
is for research use only, so this site has no problem text.

## Start here

- [Board setup](BOARD_SETUP.md): the organizers' guide to set up the board and the

- [Challenge context](CHALLENGE_CONTEXT.md): the team's planning notes and research
  for the challenge.
- [UNO Q board reference](UNO_Q_BOARD_REFERENCE.md): the board's hardware and limits.
